# Casino lobby asset pack v1 — prototype

Extracted from the approved casino selection concept. Includes three independent 1200×520 artwork PNGs, two RGBA locked-state overlays, a transparent frame, full-card visual references, and a manifest.

**Important:** This is a compositing/integration starter, not production-ready source artwork. Text on casino building signage is baked into the source; UI labels, unlock values, and buttons must be rendered separately by the app. The card artwork has been cropped and resized.

**Unlocks:** Desert Palms immediately; White Buffalo when bankroll first reaches $100,000; Morongo Sky when bankroll first reaches $1,000,000. Permanent once unlocked.

**Audio:** Keep casino-specific music as separate future assets in the audio registry; no audio is included here.
