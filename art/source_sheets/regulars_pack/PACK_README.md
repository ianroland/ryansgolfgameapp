# Craps Regulars Portraits — Game Asset Pack

27 PNG files, nine characters × neutral/happy/groan. Copy the included `src/assets/casino/npcs/regulars/` tree into the game repository.

All portraits are 256×256 RGBA with transparent backgrounds, generated from the approved concept sheet. Note: the image generator originally rendered a pale checkerboard background; automated background removal was applied, so visually QA edges and transparency before shipping. Pixel-art look and expressions are concept art, not pixel-perfect production assets.

Character IDs and filenames match `CRAPS_REGULARS_PORTRAITS.md`. See `manifest.json` for every path and file size.
