# Casino Tipping & Relationships V2

Transparent RGBA PNG UI prototype pack, recreated as clean isolated elements using the approved concept palette. Includes 220x160 tip tray, 9 button states (128x128), 3 feedback icons (48x48), 5 tier badges (128x128), 900x160 tier-up banner, 6 consecutive tip-flight frames (128x128), blank dialogue panel, and the original concept sheet.

**Important:** These are original programmatic pixel-style UI prototypes, not precise extractions of the illustrated concept. The buttons have baked $5/$25/$100 labels; for location-specific tip sizes, render numbers in code or request blank buttons. Existing dealer art is not replaced. No music or code included. Test and approve in actual game viewport before production use.
